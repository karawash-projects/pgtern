# Security policy

Security fixes are released for the most recent minor version of pgtern.

| Version | Supported |
|---------|-----------|
| 0.4.x   | Yes       |
| < 0.4   | No        |

Report suspected vulnerabilities privately, using GitHub's **Security → Report a vulnerability** feature on the [repository](https://github.com/karawash-projects/pgtern). Do not open a public issue or pull request for a vulnerability.

The full policy is in [SECURITY.md](https://github.com/karawash-projects/pgtern/blob/main/SECURITY.md).
