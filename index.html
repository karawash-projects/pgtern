pgtern

A PostgreSQL client for Python with zero runtime dependencies. Blocking and asyncio APIs, pure Python, standard library only.

Status: Beta. pgtern is at version 0.x, and the API may change before 1.0. See the changelog.

Install

pip install pgtern

Requires Python 3.11 or newer.

Quick start

import pgtern
from pgtern.rows import dict_row

with pgtern.connect("postgresql://app:secret@localhost/app", row_factory=dict_row) as conn:
    with conn.transaction():
        conn.execute("INSERT INTO notes (body) VALUES (%s)", ["hello"])
    print(conn.execute("SELECT id, body FROM notes ORDER BY id").fetchall())

Async

import asyncio
from pgtern import aio

async def main():
    async with aio.AsyncConnectionPool("postgresql://app:secret@localhost/app", min_size=2, max_size=10) as pool:
        async with pool.connection() as conn:
            cur = await conn.execute("SELECT %s::int", [1])
            print(cur.fetchall())

asyncio.run(main())

Features

  • No runtime dependencies, and no C extensions or build step.
  • Blocking and asyncio APIs with the same names and behaviour.
  • SCRAM-SHA-256 authentication, with channel binding over TLS.
  • TLS modes from disable to verify-full.
  • Connection pools with liveness checks and a fork-safe reset.
  • Parameters are always sent separately from the SQL text.
  • Server-side cursors, batched executemany, COPY, pipelines and notifications.
  • Query hooks for logging and tracing, without bound parameter values.

Compatibility

  • PostgreSQL 14, 15, 16, 17 and 18.
  • Python 3.11, 3.12 and 3.13, tested in continuous integration on Linux.
